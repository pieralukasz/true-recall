# Installation

## Requirements

- Obsidian v1.5.0 or later
- An Obsidian vault

## Install from Community Plugins

1. Open Obsidian Settings
2. Go to **Community Plugins**
3. Disable **Restricted mode** if enabled
4. Click **Browse** to open the community plugins directory
5. Search for **"True Recall"**
6. Click **Install**
7. Once installed, click **Enable**

## Manual Installation

If the plugin isn't available in the community browser yet:

1. Download the latest release from [GitHub Releases](https://github.com/your-repo/releases)
2. Extract the files to your vault: `.obsidian/plugins/true-recall/`
3. Restart Obsidian
4. Enable the plugin in Settings → Community Plugins

## First-Time Setup

After enabling True Recall:

1. **AI Configuration** (Optional) — Go to Settings → True Recall → AI to configure your OpenRouter API key or True Recall subscription for AI features
2. **FSRS Settings** — Review the default FSRS parameters in Settings → True Recall → FSRS (defaults work well for most users)
3. **Day Start Hour** — Set when your "day" begins (default: 4 AM, matching Anki behavior)

## Verify Installation

Open the command palette (Cmd/Ctrl + P) and search for "True Recall". You should see commands like:

- Open dashboard
- Open flashcard panel
- Review flashcards from current note

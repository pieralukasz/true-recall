# Keyboard Shortcuts

Quick reference for all True Recall keyboard shortcuts.

## During Review

### Answer Rating

| Key | Action |
|-----|--------|
| `1` | Rate: Again |
| `2` | Rate: Hard |
| `3` or `Space` | Rate: Good |
| `4` | Rate: Easy |

### Showing Answer

| Key | Action |
|-----|--------|
| `Space` | Show answer (when hidden) |
| `Cmd/Ctrl + Enter` | Submit typed answer (type-in mode) |

### Card Actions

| Key | Action |
|-----|--------|
| `E` | Edit card |
| `!` (Shift+1) | Suspend card |
| `-` | Bury card until tomorrow |
| `=` | Bury note (all siblings) until tomorrow |
| `M` | Move card to another note |
| `A` | Add new flashcard |
| `T` | Cycle type-in mode (Off → AI → Diff → Off) |
| `P` | Change FSRS preset for card |

### Session Actions

| Key | Action |
|-----|--------|
| `Cmd/Ctrl + Z` | Undo last answer |
| `Escape` | End session |
| `?` | Show keyboard shortcuts help |

## Card Browser

| Key | Action |
|-----|--------|
| `j` / `↓` | Move down |
| `k` / `↑` | Move up |
| `Enter` | Edit selected card |
| `Space` | Toggle selection |
| `Cmd/Ctrl + A` | Select all |
| `Escape` | Clear selection |

## Flashcard Panel

| Key | Action |
|-----|--------|
| `Enter` | Edit selected card |
| `Delete` | Delete selected card |
| `Escape` | Deselect |

### Setting Custom Shortcuts

1. Open Obsidian Settings
2. Go to Community Plugins
3. Click keyboard icon next to True Recall
4. Set your preferred shortcuts

## Customizing Shortcuts

### Obsidian's Shortcut System

True Recall uses Obsidian's command system, so you can:

1. Set custom shortcuts in Settings
2. View all commands in Command Palette
3. Use with macro plugins (e.g., Hotkeys for specific files)

### Recommended Shortcuts

| Command | Suggested Shortcut |
|---------|-------------------|
| Review current note | `Cmd/Ctrl + R` |
| Open dashboard | `Cmd/Ctrl + D` |
| Open flashcard panel | `Cmd/Ctrl + P` |
| Undo flashcard action | `Cmd/Ctrl + Shift + Z` |

## Tips

### 1. Learn the Basics First

Start with:
- `Space` to show/rate
- `1-4` for rating
- `Cmd/Ctrl + Z` for undo

### 2. Use Keyboard Over Mouse

Keyboard is faster for reviewing.

### 3. Customize for Your Workflow

Set shortcuts that match your muscle memory.

### 4. Print a Cheat Sheet

Keep a reference until shortcuts become automatic.
